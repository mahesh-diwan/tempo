# Tempo Milestones 1–2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the greenfield Tempo workspace, then prove anonymous YouTube Music search and playback without any browser engine.

**Architecture:** A Cargo workspace with focused crates. `tempo-model` holds shared plain types. `tempo-youtube` owns InnerTube search and direct-URL stream resolution. `tempo-player` wraps libmpv. `tempo-core`, `tempo-platform`, and `tempo-ui` are compiling stubs in this phase. `apps/tempo` is the future app shell; `apps/spike` is the live extraction harness that produces the gate report.

**Tech Stack:** Rust 1.99, edition 2021, tokio, reqwest (rustls), libmpv2 4, rustypipe 0.11, serde, thiserror, clap-free argument parsing.

**Spec:** `docs/superpowers/specs/2026-11-10-tempo-design.md`

## Global Constraints

- Package and binary name: `tempo`. Version `0.1.0`. License `GPL-3.0-or-later`.
- App ID: `io.github.mahesh-diwan.tempo`. MPRIS name: `tempo`. Window title: `Tempo`.
- No Tauri, GTK, WebKit, Node, pnpm, or JavaScript engine in any dependency.
- No account, cookie, cipher, PoToken, or `WEB_REMIX` stream path.
- Stream clients, in order: `VISIONOS`, `ANDROID_VR_1_65_10`, `ANDROID_VR_1_43_32`. `IOS` is forbidden.
- Fallback: `rustypipe` whole-video resolution.
- Anonymous requests only. `Session` stays empty in this phase.
- Live network tests are opt-in with `--features live-tests`; the default `cargo test` is offline.
- Linux x86_64. libmpv 2.x is required at build and run time.
- Gate: 50 tracks from 10 queries; every query returns results; at least 45 tracks play for 10 seconds.
- Source for copied modules: `/home/mahesh-diwan/SPECTRE/Projects/ryotunes`, read-only.
- Every copied module is rewritten to the new crate names and boundaries. No path dependency on the old repository.

## Review Focus

1. **No audio device or headless session** — `tempo_player::Player::new` must return an error, never panic, and the app must start. Test in Task 4.
2. **Ciphered-only direct-client response** — the resolver must skip the format and try the next client, not return a broken URL. Test in Task 6.
3. **Search response with no song renderers** — must return an empty list, not an error or panic. Test in Task 5.
4. **Missing `streamingData`, `expiresInSeconds`, or playability status** — must be treated as a failed client and fall through. Tests in Task 6.
5. **Non-ASCII search queries** — Hindi, Tamil, and accented Latin queries must encode safely and survive the round trip. Test in Task 3.

#!/usr/bin/env bash
# Measure a running Ryotunes process. Usage: scripts/baseline.sh [process-name]
set -u
name="${1:-ryotunes}"
pids=$(pgrep -x "$name" || true)
if [ -z "$pids" ]; then
  echo "no process named $name" >&2
  exit 1
fi
main=$(echo "$pids" | head -1)
pss=$(awk '/^Pss:/ {print $2}' "/proc/$main/smaps_rollup" 2>/dev/null)
pss=${pss:-0}

echo "pid=$main"
echo "pss_kib=$pss"
echo "pss_mib=$((pss / 1024))"
echo "threads=$threads"
echo "processes=$count"
ps -o pid=,comm= -p "$(echo "$pids" | paste -sd, -)"

- `resolve_stream` calls `resolve_with` with a fetch closure that calls `it.player(...)` and serializes the response to `serde_json::Value`; on `NoStream`, it then calls `rustypipe_fallback::resolve(video_id, prefer_high)`.

#[derive(Debug, serde::Serialize, serde::Deserialize)]
pub struct TrackReport {
    pub query: String,
    pub video_id: String,
    pub title: String,
    pub status: String,
    pub client: Option<String>,
    pub itag: Option<i64>,
    pub elapsed_ms: u128,
    pub error: Option<String>,
}

#[derive(Debug, serde::Serialize, serde::Deserialize)]
pub struct SpikeReport {
    pub queries: Vec<String>,
    pub tracks: Vec<TrackReport>,
}

impl SpikeReport {
    pub fn playable(&self) -> usize {
        self.tracks.iter().filter(|t| t.status == "played").count()
    }

    pub fn queries_with_results(&self) -> usize {
        let mut seen: Vec<&str> = Vec::new();
        for t in &self.tracks {
            if t.status != "search_empty" && !seen.contains(&t.query.as_str()) {
                seen.push(&t.query);
            }
        }
        seen.len()
    }

    pub fn gate_passes(&self) -> bool {
        self.queries_with_results() == self.queries.len()
            && self.tracks.len() == 50
            && self.playable() * 100 >= 90 * self.tracks.len()
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    fn track(query: &str, status: &str) -> TrackReport {
        TrackReport {
            query: query.to_owned(),
            video_id: "vid".to_owned(),
            title: "Title".to_owned(),
            status: status.to_owned(),
            client: None,
            itag: None,
            elapsed_ms: 1,
            error: None,
        }
    }

    fn report_with_played(played: usize) -> SpikeReport {
        let queries: Vec<String> = (0..10).map(|i| format!("q{i}")).collect();
        let mut tracks = Vec::new();
        for query in &queries {
            for _ in 0..5 {
                let status = if tracks.len() < played { "played" } else { "failed" };
                tracks.push(track(query, status));
            }
        }
        SpikeReport { queries, tracks }
    }

    #[test]
    fn gate_passes_at_45_of_50() {
        assert!(report_with_played(45).gate_passes());

#!/usr/bin/env python3
import json, sys

path = sys.argv[1] if len(sys.argv) > 1 else "spike-report.json"
report = json.load(open(path))
tracks = report["tracks"]
queries = report["queries"]
played = sum(1 for t in tracks if t["status"] == "played")
with_results = len({t["query"] for t in tracks if t["status"] != "search_empty"})
ok = with_results == len(queries) and len(tracks) == 50 and played * 100 >= 90 * len(tracks)
print(f"pass={played} fail={len(tracks) - played} queries={with_results}/{len(queries)} gate={'pass' if ok else 'fail'}")
sys.exit(0 if ok else 2)
